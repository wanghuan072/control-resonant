# Design direction: altered field archive

Audience: English-speaking CONTROL Resonant players finding a guide or reference.
The home page's job is to lead to the right guide, while feeling native to the game's altered architecture.

## Visual system

- Concrete paper: `#e8eae4`; document face: `#f6f7f2`.
- Archive ink: `#171b18`; structural dark: `#151b19`.
- Signal red: `#c92d25`; muted structural rules: `#bec5bc`.
- Archivo Black is reserved for major display moments, not every small heading.
- IBM Plex Sans carries navigation, reading text, lists and most section headings.
- Monospaced metadata is limited to actual dates, evidence labels and counts.

## Composition

The former equal-card portal is replaced by an altered architectural cover, a lead-story spread, a photographic location feature, an unboxed systems list and a compact topic directory.

```text
identity / quiet navigation / search
oversized game title  | staggered Manhattan image planes
introduction + guide CTA | scene caption
lead guide image + text  | two essential answers + release note
full photographic Manhattan feature | related route links
combat photograph | four unboxed system rows
source-led feature | recent editorial notes
compact topic directory / questions / footer
```

Signature: one official Manhattan scene is composed in three staggered CSS planes. The displaced geometry echoes the game's world without generating new purported game screenshots. All accompanying data remains source-labeled.

Critique of the first plan: a generic newspaper grid would repeat the previous template in another font. The revised design gives each content type a different spatial role, drops decorative section numbers and avoids six equal image cards.

Inner pages retain their H1/H2/H3, citations, tables and mobile TOC, but use a document cover, a side rail and a calmer reading column. No ornamental motion; only navigation and hover feedback. Respect reduced motion, keyboard focus and touch targets.
